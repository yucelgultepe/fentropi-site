# Fentropi.com — Site Planı

## Genel çerçeve

- **Dil:** Türkçe
- **Amaç:** Fentropi markasının çatı sitesi — Android uygulaması, müzikler,
  makaleler ve gelecekteki çalışmalar tek çatı altında.
- **Strateji:** Taslaklar arka planda hazırlanır; yayın için acele yok.
- **Uygulama durumu:** Google Play'de yayında. (TODO: mağaza bağlantısı eklenecek)

## Önerilen site haritası

```
fentropi.com              → Ana sayfa (marka + bölümlere geçiş)
fentropi.com/uygulama     → Fentropi Android uygulaması tanıtımı
fentropi.com/muzik        → Müzik çalışmaları
fentropi.com/makaleler    → Makaleler / yazılar
fentropi.com/mic          → Mic rehberi (mevcut, yayında kalabilir)
fentropi.com/gizlilik     → Gizlilik politikası / KVKK
```

## Senden gereken malzemeler (hazır oldukça)

1. **Play Store bağlantısı** — uygulamanın mağaza linki
   (örn. `https://play.google.com/store/apps/details?id=...`)
2. **Uygulama kısa tanımı** — 1–2 cümle: ne yapar, kimin için?
3. **Ekran görüntüleri** — 2–4 adet telefon ekran görüntüsü (varsa)
4. **Müzikler** — dosya/link (YouTube, Spotify vb.) ve kısa açıklamalar
5. **Makaleler** — metinler (Drive'daki `fentropi_ham_veri.md` içindekiler
   uygunsa oradan alınabilir — bağlayıcı düzelince okuyacağım)
6. **İletişim e-postası** — sitede görünmesini istediğin adres
   (örn. info@fentropi.com; GoDaddy e-posta yönlendirme kurulabilir)
7. **Sosyal medya** — varsa bağlantılar
